Status: non-effective. No runtime or machine authority exists until the exact
digest-bound owner statement is accepted.

## Scope

The proposed second and final special authorization binds one logical node,
one exact PowerShell runtime, all source and package hashes, 500 generated-only
validation cases, the accepted machine-handler package, and the existing U3K
storage contract. It allows no more than three total pre-U3K attempts under the
same digests and only for three explicitly transient process/output failures.

The U3K portion remains stricter: at most one storage attempt for exact absent
root `F:\HCAM-Quarantine`, using only sealed actions U3K-A01 through U3K-A10.
No retry is allowed after a machine or storage action begins. `B:`,
`F:\h cam`, existing-root modification, and all alternate paths remain denied.

## Successful Effect

Only complete success may write bounded sanitized evidence, synchronize the
allowlisted Phase 3 records, mark Phase 3 complete, and create one local
checkpoint commit. Push and every other remote Git action remain prohibited.

## Continuing Exclusions

The package does not authorize scanners, network or trust retrieval, installs,
updates, downloads, artifacts, models, inference, cameras, media, private or
Government data, containers, Kubernetes, profile activation, or deployment.

The exact owner statement is emitted only after final generated/static
validation and all package hashes have been resealed.
