## Phase Boundary

```text
Phase 3                                      Phase 4
anonymous observation                       correlation hypothesis
stream-local track                          proposed alert
deterministic analytic event                alert lifecycle
model/rule/evaluator provenance             reviewer decision history
alert_state = not_evaluated                 investigation timeline
        |                                          |
        +------ versioned event contract ----------+
                                                   |
                                                   v
Phase 5
operator applications and operational user experience
```

An `analytic_event` is an input. A correlation result is a hypothesis. An alert
is a reviewable operational object. None of them is an identity, legal finding,
or instruction to take coercive action.
