## Application Scope

### Intelligence Overview And Queues

The connected Intelligence Center receives grouped overview, hypothesis,
correlation-run, relationship, spatial, rule, candidate, proposed-alert,
mandatory-review, correction, and intelligence-health pages. These surfaces
consume generated adapters only and preserve loading, empty, partial, stale,
degraded, denied, conflict, failure, correction, and recovery states.

Queues use stable cursor pagination, typed filters, bounded page sizes,
deterministic server-order projections, explicit filter reset, and
authoritative list/detail navigation. The client may not create one universal
untyped queue, join unbounded datasets, order by a score as implied truth, or
offer bulk review.

### Relationship, Spatial, And Rule Views

The implementation may create the internal `RelationshipGraphRenderer`
contract, synchronized node/edge tables, and an explicit no-graph fallback.
The authoritative tables remain the complete workflow in every resource
profile. The accepted P5.2 MapLibre/deck.gl domain may render bounded generated
spatial projections without tile or provider network access.

Rule views show exact revision identity, normalized inputs, typed node traces,
time/window behavior, outcome, abstention, and limitations. Any deterministic
summary is secondary and must not omit or contradict the exact trace.

### Candidate And Proposed-Alert Views

Candidate sets use field-level evidence matrices. No top candidate is
automatically selected, no identity probability is shown as established
identity, and contradictions, missingness, staleness, calibration class,
provenance, and abstention stay visible. Proposed-alert occurrence identity is
separate from delivery and idempotency identity. Procedural priority is not
criminal severity.

### Mandatory Review And Correction

The generated server-authoritative adapter projects current policy,
independent quorum, actor eligibility, duplicate-actor denial, ETags, expected
revision, idempotency fingerprints, receipts, and allowed lifecycle commands.
Drafts remain memory only and are purged on logout, department switch, role
loss, expiry, route disposal, or window closure.

Conflict handling performs no automatic mutation retry. It requires
authoritative refetch, visible comparison, and deliberate reconsideration.
Review decisions, corrections, retractions, supersessions, and reconsideration
entries are attributable, chronological, and append only.
