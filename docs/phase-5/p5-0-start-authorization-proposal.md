## Purpose

This package converts the accepted Phase 5 architecture into one bounded P5.0
implementation decision. P5.0 implements the canonical operator-application
contract, information-architecture, journey, design, accessibility, GIS parity,
browser-security, generated-fixture, validation, and evidence foundations.

It does not build or run the React application. Frontend framework setup,
source import from `hcam-1-0/final-ui`, renderer integration, and product UI
components remain deferred to P5.1 and later subphases.

## GIS Result

The implementation must turn the accepted GIS direction into typed,
renderer-neutral contracts and parity evidence. It must preserve the current
`GisWorkspace` layout, filters, layers, selection, focus behavior, responsive
drawers, safety labels, and approval-gated preview flow. It must also define
bounded geometry, viewport, cluster, temporal, uncertainty, correction,
degradation, localization, accessibility, and resource-profile behavior.

MapLibre 2D remains the future renderer target, but no map renderer or network
runtime is authorized in P5.0. Optional 3D remains supplementary, default-off,
and subordinate to authoritative 2D and accessible list paths.
