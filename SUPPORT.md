# Support

## Setup And Development

Use [ONBOARDING.md](ONBOARDING.md) for project orientation and
[TEAMMATE_SETUP.md](TEAMMATE_SETUP.md) for local setup and validation. Search
the documentation and existing issues before creating new work.

## Questions And Ideas

Use [GitHub Discussions](https://github.com/hcam-1-0/model-m-1/discussions)
for collaborator questions, design exploration, and proposals that are not yet
implementation-ready. Convert an agreed outcome into a structured issue before
starting material work.

## Bugs, Tasks, And Decisions

Use the repository's issue chooser and select the matching form. Include a
minimal synthetic reproduction, environment details without personal or device
identifiers, expected behavior, actual behavior, and validation evidence.

## Security And Sensitive Material

Follow [SECURITY.md](SECURITY.md). Never post secrets, private endpoints, live
media, Government data, police records, personal data, or exploitable details
in GitHub content.

## Operational Limit

This repository is not an emergency, dispatch, or live operational support
channel. GitHub issues and discussions do not authorize camera access,
operational actions, deployment, or changes to external systems.
