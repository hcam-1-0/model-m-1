# Sentinel probe fixtures

This directory is reserved for redacted, metadata-only development fixtures
created by `tools/sentinel_cctv_probe.py registry-export`.

- The repository **must not store CCTV footage**, recordings, credentials,
  tokens, cookies, signed media URLs, or unredacted government data.
- Generated `registry-export` JSON files are ignored by Git.
- Only deliberately reviewed synthetic examples may be committed.
